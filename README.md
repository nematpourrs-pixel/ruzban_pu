# روزبان — اندروید عمومی

مخزن `ruzban_pu` برای کد **عمومی** اپ اندروید روزبان است. هیچ رمز، API Key خصوصی یا کد بک‌اند نباید اینجا قرار گیرد.

**وضعیت:** نمونه اولیه کلاینت، نه نسخه نهایی و امضاشده برای کافه‌بازار. ساخت APK مستلزم تنظیم آدرس HTTPS وب‌اپ و عبور از آزمون‌های انتشار است.

نسخه وب‌اپ و سرور در مخزن خصوصی `ruzban_pr` نگهداری می‌شود.
